# MeshCrossway Android

Native portrait APK prototype. This first alpha validates independent Meshtastic and MeshCore BLE connections and protocol identification. It does not yet provide messaging or maps.

See [Android development and installation](../docs/android-apk.md) and [issue #187](https://github.com/Renbrant/MeshCrossway/issues/187).

```sh
# JDK 17 + Android SDK 35
./gradlew assembleDebug lintDebug
```
