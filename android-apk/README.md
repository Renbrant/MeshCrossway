Includes independent Meshtastic/MeshCore messaging, nodes/channels, persistent local history/drafts, unread counts, search and reconnection. Real-radio validation of messaging remains pending. See [installation and limitations](../docs/android-apk.md).

If Android reports an incompatible signing certificate, alpha01 may need to be uninstalled before installation. Uninstalling removes app data; do not uninstall a version with message history without an export/recovery plan.
