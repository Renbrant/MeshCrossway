V1 architecture

Three ESP32-S3 brains. Two radios. One console.

The approved modular architecture has three detachable battery-powered devices linked wirelessly by BLE. The former common-carrier UART Rev A layout is historical and not the current build plan.

HOST

Waveshare ESP32-S3 Touch LCD 3.5

480×320 touch UI, Wi-Fi and read-only diagnostics, experimental MeshCore client; local GNSS and encrypted message storage are planned.

RADIO ×2

Seeed XIAO ESP32-S3 + Wio-SX1262

One dedicated module for Meshtastic and another for MeshCore Companion.

POSITION

u-blox MAX-M10S

Proposed GNSS receiver for a future Core integration; electrical, power and antenna validation remain pending.
