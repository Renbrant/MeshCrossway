Current hardware direction

One touchscreen Core. Two independent radio modules.

MeshCrossway is being developed as three separate devices connected over Bluetooth Low Energy: a touchscreen controller, one Meshtastic radio and one MeshCore radio. The radios keep their own native networks and continue operating independently.

CORE · ACTIVE FIRMWARE TARGET

Waveshare ESP32-S3-Touch-LCD-3.5 Rev2.0

The 480 × 320 touchscreen runs the interface, GNSS workflow, microSD storage and two independent BLE connections.

RADIO PODS · USER-SELECTABLE

Heltec V3 tested; compatible radios are your choice

There is no required XIAO model. Choose radio hardware that supports the native Meshtastic BLE PhoneAPI or MeshCore BLE Companion with compatible firmware. Heltec V3 is the current development-tested setup; validate other model and firmware combinations individually.

POSITION

u-blox MAX-M10S GNSS

Provides local position and timing for the map, track and location workflows.

Hardware qualification is ongoing. Pod power and batteries, final enclosures, antenna placement, RF coexistence and longer runtime testing still need validation. The integrated Rev A UART/PCB design is archived and is not the current assembly baseline.
