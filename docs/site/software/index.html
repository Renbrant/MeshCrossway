Software architecture

Independent radios. Shared experience.

The host firmware owns the UI and local features while the radio modules stay close to their upstream Meshtastic and MeshCore implementations.

Host firmware

LVGL touchscreen UI, real MeshCore Companion client, Wi-Fi/BLE state, 93 color emoji glyphs and diagnostics. GNSS, maps and encrypted chat history are not yet active.

Meshtastic adapter

Planned Meshtastic protobuf PhoneAPI over BLE to an independent MX-M Pod; no working application message adapter yet.

MeshCore adapter

Experimental MeshCore Companion binary GATT-over-BLE client: contacts, channels, messages and command tools, with a single active BLE session.

Firmware on main: v0.7.6 experimental. Owner-tested rollback: v0.6.8. Swipe UI, battery and refined chat are still in open v0.7.7 PR #54. Storage encryption/journal work is paused. Meshtastic and MeshCore never bridge, relay or synchronize messages. Current status and limitations.
