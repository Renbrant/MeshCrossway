Dedicated controller — firmware v0.10.5

Separate radio adapters

Native Meshtastic PhoneAPI and MeshCore Companion BLE sessions, with their own pairing, identities, messages, channels and configuration. Users can choose compatible radios; Heltec V3 is development-tested, and other model/firmware combinations require validation.

Maps and navigation

GNSS position and clock, street/topographic maps, local street night view, cached SD tiles, tracks, POIs, folders and GPX. Uncached maps need Wi-Fi; live position sharing remains future work.

Local browser companion

Use a browser on the same local network for messages, radio settings, route previews, folders and GPX downloads. Manual screenshots are available; continuous remote touchscreen control is not enabled.

Node visibility and retention

Independent marker shapes, sizes and colors; optional grouping; 32-row manual-refresh node lists. Age colors distinguish under 24 hours, 1–7 days and older/unknown observations. A saved 0–365 day limit removes ordinary local discoveries while protecting favorites, conversations and uncertain timestamps.

Screen and connectivity

Automatic 180-degree landscape orientation, saved rotation lock, manual flip/reference correction, brightness and screen timeout. Bluetooth and Wi-Fi can be controlled in settings.

Measured resource management

SD work runs through existing storage workers. Bounded console memory records and internal/PSRAM/DMA snapshots support testing. Node deletion reduces populated records; fixed table reservations remain allocated. DMA memory is a subset of internal RAM.

Stable releases retain the exact accepted binary by checksum. v0.9.28 is the previous stable recovery; v0.9.25 and v0.9.16 remain earlier recovery images. Mechanical, battery, RF coexistence and broader endurance qualification continue separately.
