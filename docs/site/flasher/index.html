Recovery: flickering or rebooting display

Connect the Waveshare Rev2.0 display to your computer with a USB data cable. Leave the computer on its normal Wi-Fi network.
Choose v0.4.0 — Recommended recovery above, and select Install. v0.3.0 is another tested fallback.
If the USB serial port is unavailable because the new firmware keeps restarting, enter ESP32-S3 download mode using the board's BOOT and RESET controls, then retry connecting.
For a clean downgrade, you can choose Erase device in the installer. This will also erase saved Wi-Fi credentials and other settings.
Target limitation: these images are for the Waveshare ESP32-S3-Touch-LCD-3.5 non-B, Rev2.0 display. Do not flash a XIAO radio module or a Waveshare 3.5B with this image. Firmware installation may overwrite data.

How versions are maintained

The firmware listed above is compiled automatically in GitHub Actions from pinned historical commits. The browser installs the compiled binary; it does not compile ESP-IDF source code locally. Each build is archived in its own directory with its own manifest and SHA-256 checksum. New releases do not replace the recovery images.
