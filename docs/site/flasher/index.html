MeshCrossway Web Flasher.

A browser-based path from development build to hardware — no Arduino IDE required for routine flashing.

DEVELOPMENT · BUILD PENDING

Display / Host — Waveshare ESP32-S3

The flasher integration is ready, but the repository does not yet contain a verified merged binary for this board. Installation is intentionally locked until the first hardware-tested image is published.

How it will work

Connect the supported MeshCrossway board to your computer using a data-capable USB cable.
Open this page in a browser with Web Serial support and select the correct USB serial device.
Choose the desired verified build and confirm installation. Experimental builds will remain clearly labeled.
Important: flashing can erase configuration and a wrong image can make a board temporarily unbootable. Only target-specific, verified MeshCrossway builds will be exposed here.

Planned targets

Host: Waveshare ESP32-S3-Touch-LCD-3.5. Radio A: XIAO ESP32-S3 + Wio-SX1262 / Meshtastic. Radio B: XIAO ESP32-S3 + Wio-SX1262 / MeshCore Companion. Radio flashing will only be added after we verify the exact upstream build and partition requirements.

This page is built around ESP Web Tools, which uses Web Serial and a firmware manifest to install ESP32 images over HTTPS.
