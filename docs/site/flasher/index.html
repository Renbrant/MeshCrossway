Recovery: touchscreen freezes or display reboots

Connect the Waveshare Rev2.0 display to your computer with a USB data cable. Leave the computer on its normal Wi-Fi network.
Select v0.8.2 — hardware-tested for rollback after an experimental build. Older versions are no longer listed in the Web Flasher.
If the USB serial port is unavailable because the new firmware keeps restarting, enter ESP32-S3 download mode using the board's BOOT and RESET controls, then retry connecting.
Always leave the Erase device checkbox unchecked for normal updates. An erase resets NVS and deletes saved Wi-Fi and BLE bonds. From v0.5.8, the split image writes bootloader, partition table and application without targeting NVS. Older merged installers can overwrite settings even without Erase. An SD Wi-Fi backup is plaintext and should be created before erasing. For a clean downgrade, you can choose Erase device in the installer. This will also erase saved Wi-Fi credentials and other settings.
Target limitation: these images are for the Waveshare ESP32-S3-Touch-LCD-3.5 non-B, Rev2.0 display. Do not flash a XIAO radio module or a Waveshare 3.5B with this image. Firmware installation may overwrite data.

How versions are maintained

The latest experimental firmware is automatically published after the GitHub Actions build and checks succeed; it remains explicitly labeled experimental until physical validation. The firmware listed above is compiled automatically in GitHub Actions from pinned historical commits. The browser installs the compiled binary; it does not compile ESP-IDF source code locally. Each selectable build keeps its own manifest and SHA-256 checksum. Obsolete and known-broken versions are excluded from the active Web Flasher list; historical source commits remain in GitHub.
