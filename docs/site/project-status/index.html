Project status

Android beta and controller releases.

Android and controller firmware have independent version sequences. Android 0.3.9 is the current public beta for testing, not version 1.0.0. The controller now has v0.10.5 as its accepted stable firmware baseline.

ANDROID · 0.3.9 BETA · 2026-11-10

More reliable MeshCore settings and contacts

Configuration changes are checked against the radio before success is shown. This update improves contact approval, firmware compatibility, device names, transmit power and delayed delivery confirmations.

Install as an update to keep your local data. Physical-radio testing continues.

ANDROID · 0.3.8 BETA · 2026-11-10

Clearer, more reliable radio settings

Meshtastic preset defaults, firmware compatibility and regional settings validation have been corrected. After saving, the app checks the full radio configuration and explains any difference. Bluetooth and serial settings now show their actual state, and available module controls load independently.

Install as an update over the existing app. The permanent signing identity is retained, and local messages, settings, tracks and offline maps stay in place. Physical-radio testing continues.

ANDROID · 0.3.7 BETA · 2026-11-10

Account shortcut placement

The account button now has reserved space alongside Settings and More options. It no longer floats over other toolbar controls or the Home logo when navigating or resuming the app. Includes the compact Home, inline preset and 15-minute node activity introduced in 0.3.6.

The permanent signing identity is retained. Install over the existing app with Update; do not uninstall. This remains a public beta for testing.

ANDROID · 0.3.6 BETA · 2026-11-10

Compact Home and recent node activity

The synchronized Meshtastic preset appears beside Ready. Bluetooth device names are removed from the Home radio cards while BLE signal remains visible. Both node cards count activity within 15 minutes and refresh automatically while Home is visible. Earlier 0.3.4 and 0.3.5 changes added in-place radio-save progress and confirmation of firmware-normalized preset defaults.

Build, protocol, storage and Android API 29/35 checks passed. The permanent signing certificate is unchanged. Physical-radio and broader compatibility testing continues; this remains a public beta.

ANDROID · 0.1.0 BETA

Functional baseline for public testing

Preserves the accepted alpha07 functionality under the new version sequence. APK/lint/protocol checks and Android API 29/35 smoke tests passed. Broader phone/radio compatibility testing continues. This is not version 1.0.0.

0.1.1, 0.1.2 and later patch versions cover small changes. 0.2.0 and later minor versions cover substantial work. 1.0.0 is reserved for the first production release.

v0.10.x and v0.9.x releases

v0.10.5 · STABLE

Offline maps and area selection

Adds offline raster map packs, area downloads, saved-area previews and resumable storage cleanup. The user selected this version as stable after device use.

v0.9.32 · PREVIOUS STABLE

Raster map gestures and magnification

Restores the v0.9.31 raster map, adds two-finger pinch zoom and a saved 1.25x magnification option. The user confirmed the build is functioning very well and extremely stable.

v0.9.28 · PREVIOUS STABLE

Node age and retention

Adds independent last-heard colors and a saved 0-365 day retention limit. Protects favorites and conversations, filters stale imports, and preserves legacy SD archives.

v0.9.27 · PREVIOUS CANDIDATE

Rotation reference correction

A manual Flip 180 also corrects and saves the automatic rotation reference, preventing AUTO from undoing the readable orientation.

v0.9.26 · SUPERSEDED

Landscape orientation

Uses the built-in accelerometer for 180-degree rotation, with a saved quick-panel lock and manual flip. Reuses the telemetry task and LCD hardware mirrors.

v0.9.25 · EARLIER RECOVERY

Map controls and stable baseline

Earlier device-tested stable image. Includes independent network styles, zoom dismissal, local night maps and corrected MeshCore GPS markers.

v0.9.24 · PREVIOUS CANDIDATE

Optional map grouping

Adds a saved switch to show individual markers instead of nearby groups.

v0.9.23 · PREVIOUS CANDIDATE

Reliable map HTTPS path

Uses software AES to avoid observed hardware-AES DMA allocation failures; encryption and certificate verification remain enabled.

v0.9.22 · PREVIOUS CANDIDATE

Wi-Fi RX memory experiment

Moves Wi-Fi RX code from IRAM to flash; the compiled shared-RAM footprint decreases by 9,472 bytes.

v0.9.21 · PREVIOUS CANDIDATE

Allocation attribution

Adds bounded console records identifying task, allocation API and DMA/internal memory requirements.

v0.9.20 · PREVIOUS CANDIDATE

Bounded map groups

Replaces long group text with four fixed preview rows and explicit zoom.

v0.9.19 · PREVIOUS CANDIDATE

Console memory diagnostics

Adds bounded memory samples and task stack observations through the console.

v0.9.18 · EXPERIMENTAL

Recent node list

Shows up to 32 recently heard nodes per protocol from the last 14 days, retains MeshCore favorites, adds manual refresh and fixed card positions, and removes repeated message-history scans.

v0.9.17 · EXPERIMENTAL

Fixed layout and memory diagnostics

Fixes overlapping node and channel cards with fixed row positions and spacing. Adds a memory snapshot for internal RAM, PSRAM, DMA-capable RAM and UI stack headroom.

v0.9.16 · PREVIOUS STABLE

Node types and stack stability

Identifies people, repeaters, rooms and sensors with compact badges; shows short IDs, route type and last-heard age. Uses simpler labels to fix an LVGL stack overflow. Hardware-tested stable release.

v0.9.15 · EXPERIMENTAL

Node and channel visual refresh

Refreshes node and channel cards with network markers, aligned metadata and a compact add-channel sheet in the project’s dark and orange palette.

v0.9.14 · EXPERIMENTAL

Node list spacing

Uses a vertical layout with fixed-height cards and consistent gaps so each detail stays on its own line.

v0.9.13 · EXPERIMENTAL

Non-overlapping node cards

Separates node names, last-heard time, unread counts and traffic totals into fixed-height lines with truncation.

v0.9.12 · EXPERIMENTAL

Responsive node list rendering

Draws node rows in small timed batches to reduce LVGL stalls and watchdog delays while keeping the list usable.

v0.9.11 · EXPERIMENTAL

Startup stability

Defers Home-card refresh to the LVGL timer to avoid a reboot caused by stack use during startup.

v0.9.10 · EXPERIMENTAL

Radio controls and node list

Adds on-device Wi-Fi and Bluetooth power controls, a Bluetooth stop action during startup, safer BLE startup handling and a fixed node-list viewport.

v0.9.9 · EXPERIMENTAL

Node and channel layout

Aligns node and channel names, unread counts and activity in compact columns; handles long names without overlap.

v0.9.8 · EXPERIMENTAL

List responsiveness

Batches node and channel rows, improves node ordering and shows direct-message and channel unread totals.

v0.9.7 · EXPERIMENTAL

Node and channel details

Adds vertical node lists, sorting by last heard or distance, message and traffic counts, channel unread totals and channel creation shortcuts.

v0.9.6 · EXPERIMENTAL

Map memory fix

Moves the map worker stack to PSRAM, performs map setting writes on the UI task and reports allocation failures.

v0.9.5 · EXPERIMENTAL

Bluetooth memory fix

Reuses the existing BLE coordinator task for reconnect and pairing, avoiding another large internal-RAM task allocation.

v0.9.4 · EXPERIMENTAL

Bluetooth startup memory fix

Starts the Bluetooth controller before Wi-Fi to avoid a boot loop caused by limited contiguous internal RAM.

v0.9.3 · EXPERIMENTAL

Map cluster stability

Fixes an LVGL task stack overflow that occurred when opening nearby-node clusters on the map.

v0.9.2 · EXPERIMENTAL

Map node labels and clusters

Adds short node labels, tap-for-details, proximity clusters, marker sizes and activity colors based on recent radio timestamps.

v0.9.1 · EXPERIMENTAL

Compact settings navigation

Makes radio-setting menus more compact and adds clear Back navigation on the device and in remote access.

v0.9.0 · EXPERIMENTAL

Separate radio settings

Organizes Meshtastic and MeshCore settings into their own category menus.
