# MeshCrossway Android 0.4.13 beta

The **Home** screen now shows the health of the interference between the two radios,
in place of the "Open unified map" shortcut (the map stays in the bottom navigation).

- Two compact gauges, the same as on the RF coexistence page: **packets lost to the other
  radio** and **peak power at the other radio**.
- A status line (low, some or high interference) and how many settings can still reduce it,
  or a note when Meshtastic transmission is off.
- Tap the panel to open **Settings → RF coexistence** with the full dashboard, presets and
  advanced settings introduced in 0.4.12.

Install over the current app **without uninstalling**. Version code 47, same permanent
signing certificate and data format.
