# Archived MeshCrossway UI concepts and screenshots

> **Historical design reference — moved from the project README on October 28, 2026.** The screens below are snapshots of earlier **browser-based UI concepts**, not current screenshots from the Waveshare device, and may not match the current interface, firmware, navigation or final three-device architecture. **Do not use them as a source of current UI requirements.** The v0.4.0 Waveshare firmware remains the stable physical display baseline; v0.5.0/v0.5.1 are known unstable. The two simultaneous BLE radio connections are still being developed.

[UI prototype documentation](README.md) · [Live browser simulator](https://renbrant.github.io/MeshCrossway/) · [Approved modular architecture](../modular-architecture.md)
