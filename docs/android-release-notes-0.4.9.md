# MeshCrossway Android 0.4.9 beta

Prepares MeshCrossway for distribution on Google Play.

- **Delete your account from the app.** Account & sync now has *Delete account and
  cloud data*, which permanently removes your sign-in identity, synchronized
  messages, favorites and cloud GPX tracks. The same option is available on the
  account website. Data stored only on your phone is not affected.
- **Privacy policy.** A link to the new privacy policy is shown in Account & sync,
  and the policy is published at https://meshcrossway.renbrant.com/privacy/.
- **Android 16 target.** The app now targets Android 16 (API level 36), as Google
  Play requires for new apps and updates. The Account & sync screen scrolls and
  keeps clear of the system bars.
- Builds can now be produced as Android App Bundles for Google Play, signed with the
  same permanent certificate as the GitHub APKs.

Install over the current app **without uninstalling**. Version code 43, same
permanent signing certificate and data format. Field testing remains pending.
