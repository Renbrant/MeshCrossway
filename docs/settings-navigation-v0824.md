# Radio settings navigation redesign — v0.8.24

Candidate changes: reorganized local Meshtastic and MeshCore configuration lists into selectable categories; added category filtering and search to remote radio settings; redesigned setting cards for clearer labels and save actions. MeshCore advanced commands remain available in their own category.

This candidate also moves GNSS origin data into the HTTP request boundary so distance sorting stays testable in the remote messaging fixture. v0.8.23 remains the selected stable firmware.
