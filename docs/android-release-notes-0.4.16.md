# MeshCrossway Android 0.4.16 beta

- **Battery in the card's top bar.** On Home, each radio's battery icon and voltage now sit
  beside the network name (MESHTASTIC / MESHCORE), so they no longer compete with the
  LoRa frequency on the bottom line.
- **Read conversations from where you left off.** Opening a conversation with unread messages
  now starts at the first unread message, below a "new messages" divider, instead of jumping to
  the latest one. Scroll down to read the rest. Messages that were unread when you opened the
  conversation are marked **● NEW** with a border in the network's colour until you leave it.
  Conversations without unread messages still open at the latest message.

Install over the current app **without uninstalling**. Version code 50, same permanent
signing certificate and data format.
