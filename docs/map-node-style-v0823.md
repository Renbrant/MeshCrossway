# Per-network map node icon and color settings — v0.8.23

Map Options now has separate Meshtastic and MeshCore controls for marker shape (circle, square or cross) and marker color (Auto, orange, cyan, green, red, purple, yellow or white). Auto preserves the distinct protocol colors. Marker size and the node-name visibility setting remain shared.

Saved map preferences are migrated from the previous format automatically. Existing shared icon and color selections are carried forward to both networks, and existing size, visibility and label settings are preserved.

v0.8.17 remains the recommended stable release; v0.8.23 is a candidate pending firmware build and device validation.
