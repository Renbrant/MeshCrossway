# v0.9.0 settings navigation candidate

This candidate reorganizes radio configuration using the WadaMesh repeater-management pattern: a category landing menu, focused category pages, concise labels, clear back navigation, and grouped controls.

Meshtastic and MeshCore remain separate throughout. The device UI and remote access each start from their own network settings and category menus. Existing radio-specific fields, read/write operations, confirmation prompts, and firmware capability checks remain in place.

The v0.8.26 image remains the selected stable firmware while v0.9.0 awaits device validation.
