# MeshCrossway Android 0.4.14 beta

Simpler RF coexistence screens.

- **Home:** the interference panel is now one slim row, the same height as Remote Access,
  with two thin bars instead of gauges: **Loss** (packets lost to the other radio) and
  **Peak** (power at the other radio). Tap it to open the full page.
- **Settings → RF coexistence:** the main view keeps the basic setup (dashboard,
  Meshtastic transmission switch and presets). **Advanced settings** is now a button that
  expands the antenna spacing and every setting of both radios, with their pros and cons.

Install over the current app **without uninstalling**. Version code 48, same permanent
signing certificate and data format.
