# Emoji coverage audit — v0.9.29

Reference: `ALLFATHER-BV/wadamesh` at `53d17d0b0f22fc5fe460e13d5ef2e0d3008ca03a`. Only Unicode mapping facts were extracted; no implementation or bitmap bytes are copied.

The reference declares 272 images but has 277 codepoint mappings: 272 visible entries and 5 transparent placeholders.

Legacy: 93 glyphs. New catalog: **750 glyphs**, including 258 flag pairs, 165 tone sequences and 18 ZWJ sequences. Missing visible reference mappings: **0**.

Legacy missing mappings: 212. The original U+E000..U+E05C assignments and exact existing 14px pixels are retained.

Transparent reference entries: U+200D, U+26A7, U+FE0E, U+FE0F, U+1F1F8. ZWJ/VS are sequence controls; the zero-mapped transgender sign is supported through the composed flag. Standalone regional indicators do not identify a country; the visible reference U+1F1F1 is covered as that Unicode letter, not mislabeled as a country flag.

All indexed-4 sprites occupy 121,500 pixel/palette flash bytes; aligned storage is 123,000 bytes (+ one string terminator per 64-sprite block). Two padding bytes align each palette to four bytes. No full atlas or descriptor table is allocated in RAM. The old runtime atlas used 24,552 PSRAM bytes; the new shared display scratch uses at most 1,200 PSRAM bytes and one image font. Firmware-level flash/DRAM changes must be measured from the CI ELF, not inferred from this asset count.

## Reproduction

`python scripts/build_emoji_catalog.py --cache /path/to/input-cache` downloads only missing pinned build-time inputs, checks their SHA-256 and regenerates the append-only registry, sort order, sprites and report. Reproduce with the Pillow/FreeType/RAQM versions recorded in `scripts/emoji/coverage.json`. Independently verify the committed mapping facts with `python scripts/build_emoji_catalog.py --verify-reference /path/to/emoji_data.c`, fetched from the pinned reference commit and path in `scripts/emoji/reference_catalog.json`; the command checks its source hash and extracts only the Unicode-to-visible/transparent mapping facts. Normal CI verifies the committed bytes offline using `scripts/test_emoji.py`; no font/image fetch happens on the device.

This is explicit catalog coverage, not a claim to render every Unicode emoji. Unlisted clusters, text-presentation variants, malformed UTF-8 and allocation failure have tested fallback behavior.
