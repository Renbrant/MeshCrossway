# Adjustable map node size — v0.8.21

Map Options adds four persistent marker sizes: 18, 22, 26 and 30 pixels. The existing setting now draws nodes at 18 pixels by default, so older saved map preferences also become easier to see without requiring a reset. Meshtastic and MeshCore keep their distinct marker colors and their selected circle, square or cross shape.

On the map action rail, Map Options is now the third item, directly below Zoom. This keeps frequently used marker controls close to the map while preserving the existing settings page.

v0.8.17 remains the recommended stable release; v0.8.21 is experimental pending device confirmation.
