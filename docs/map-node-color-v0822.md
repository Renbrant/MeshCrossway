# Configurable map node colors — v0.8.22

Map Options adds a persistent Node color selector. Auto is selected by default and keeps Meshtastic and MeshCore markers in their existing distinct colors. Users can instead choose one marker color for nodes from either network: orange, cyan, green, red, purple, yellow or white.

The setting uses the existing saved map preference byte, so it does not change the stored configuration layout. The selection applies to both radios and works with all marker shapes and sizes.

v0.8.17 remains the recommended stable release; v0.8.22 is a candidate pending firmware build and device validation.
