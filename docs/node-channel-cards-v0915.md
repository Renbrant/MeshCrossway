# v0.9.15 node and channel styling

v0.9.15 is an experimental firmware candidate. The user-selected stable release remains v0.8.26.

This refresh applies the supplied MeshCore reference style to MeshCrossway’s Nodes/Networks and Groups/Channels screens while retaining the project palette:

- Circular network markers, dark card surfaces, thin outlines, and orange accents.
- Node titles and metadata are aligned in separate, predictable columns and rows. Cards preserve fixed heights and gaps so live refreshes cannot stack text on top of other text.
- Channel rows show a circular hashtag marker and keep the channel name separate from its latest-message detail.
- The channel add action opens a compact bottom sheet. It offers the public hashtag action and private channel action already supported by the firmware.

This is a presentation update. It does not change radio protocols, channel key handling, or the stable v0.8.26 firmware.
