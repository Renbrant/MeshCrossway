# MeshCrossway Android 0.4.10 beta

Home radio cards keep the same height in every state. The connection state and its
detail now share one line: **Connecting** with the current step (for example
Synchronizing) beside it in the network color, **Ready** with the Meshtastic preset,
or **Offline** with "Tap to connect".

The radio page shows the current radio settings as static information inside the top
card, next to the radio name and status. They are no longer buttons, so each settings
screen has a single entry point in the sections below.

Includes the 0.4.9 radio settings summary, tuned LoRa frequency and post-restart LoRa check.

Install over the current app **without uninstalling**. Version code 44, same permanent
signing certificate and data format. Field testing remains pending.
