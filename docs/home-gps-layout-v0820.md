# Home GPS card spacing — v0.8.20

The accuracy estimate is placed on its own line between fix status and satellite count. This prevents the two values from overlapping in the Home card. The card size and other network cards are unchanged.

Map options also support choosing circle, square or cross icons for saved radio nodes and optionally displaying their names. Firmware switches and remote companion checkboxes use compact dimensions throughout the interfaces.

v0.8.17 remains the recommended stable release; v0.8.20 is a candidate pending device confirmation.
